## 数据流

### 1. 添加文本流程

```
用户输入文本
    │
    ▼
检查嵌入缓存 (EmbeddingCache)
    │
    ├── 命中缓存 ──> 获取缓存的向量
    │
    └── 未命中 ──> 调用嵌入模型 ──> 缓存向量 ──> 获取向量
    │
    ▼
添加到向量索引 (VectorIndex)
    │
    ▼
存储到Redis
    │
    ▼
返回文档ID
```

### 2. 语义搜索流程

```
用户输入查询
    │
    ▼
检查嵌入缓存 (EmbeddingCache)
    │
    ├── 命中缓存 ──> 获取查询向量
    │
    └── 未命中 ──> 调用嵌入模型 ──> 缓存向量 ──> 获取查询向量
    │
    ▼
执行向量搜索 (VectorSearch)
    │
    ├── 纯向量搜索
    │
    └── 混合搜索（向量 + 文本 + 过滤）
    │
    ▼
返回搜索结果
```

### 3. 语义缓存流程

```
用户输入查询
    │
    ▼
检查语义缓存 (SemanticCache)
    │
    ├── 精确命中 ──> 直接返回缓存结果
    │
    ├── 语义命中 ──> 返回相似查询的结果
    │
    └── 未命中 ──> 调用LLM ──> 缓存结果 ──> 返回结果
```

## 技术选型

### 为什么选择Redis？

1. **现有基础设施**：公司已部署高性能Redis集群
2. **RediSearch模块**：支持向量搜索和全文搜索
3. **高性能**：内存数据库，支持高并发低延迟
4. **丰富的数据结构**：支持多种数据类型
5. **成熟的生态**：完善的Python客户端库

### 向量索引选择

- **FLAT索引**：精确搜索，适合小规模数据
- **HNSW索引**：近似搜索，适合大规模数据（可扩展）

### 距离度量选择

- **COSINE**：余弦相似度，适合文本语义相似度
- **L2**：欧氏距离，适合图像特征
- **IP**：点积，适合归一化向量

## 性能优化

### 1. 批量操作

使用Redis pipeline减少网络往返：
```python
# 批量添加
with redis.pipeline() as pipe:
    for doc in documents:
        pipe.hset(key, mapping=doc)
    pipe.execute()
```

### 2. 连接池

使用连接池管理Redis连接：
```python
pool = redis.ConnectionPool(max_connections=100)
redis_client = redis.Redis(connection_pool=pool)
```

### 3. 缓存预热

提前加载热点数据到缓存：
```python
def warmup_cache():
    # 加载常见查询
    for query in common_queries:
        embedding = get_embedding(query)
        embedding_cache.set(query, embedding)
```
