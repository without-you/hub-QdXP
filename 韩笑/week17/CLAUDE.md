# CLAUDE.md

## 项目概述

**项目名称**：向量检索与智能缓存服务平台

**项目目标**：构建公司内部统一的、生产就绪的向量检索与智能缓存服务平台，为上层AI应用提供简单易用、功能强大且易于扩展的Python SDK与配套服务。

**核心问题**：
- 多个团队重复开发向量数据库接入、语义缓存、对话记忆管理等模块
- 技术栈碎片化，资源利用率低
- 难以保证生产环境的性能与稳定性

**解决方案**：
- 基于已部署的高性能Redis集群
- 封装AI原生数据模式与操作
- 提供标准化的Python SDK

## 核心功能模块

### 模块1：标准历史问答存储
- 存储问答对：问题 -> 答案
- 支持快速检索已回答过的问题

### 模块2：Embedding结果缓存
- 存储文本到向量的转换结果
- 避免重复计算embedding，节约计算资源
- 降低API调用成本

### 模块3：语义缓存与对话管理
- 存储历史对话记录
- 计算对话语义相似度
- 当新问题与历史问题语义相似时，直接返回缓存结果
- 显著减少LLM调用次数，降低成本和延迟

### 模块4：意图识别
- 快速完成用户意图分类
- 支持语义路由

## 技术栈

- **向量数据库**：Redis（利用现有集群）
- **向量索引**：支持多种向量化算法
- **相似度度量**：支持余弦相似度、欧氏距离等
- **后端框架**：Python
- **应用场景**：LLM应用、RAG系统、智能客服、情感分析Agent等

## 设计原则

1. **统一性**：提供标准化接口，结束重复造轮子
2. **高性能**：基于Redis集群，支持高并发低延迟
3. **易用性**：简单易用的Python SDK
4. **可扩展性**：模块化设计，易于扩展新功能
5. **生产就绪**：经过充分测试，保证生产环境稳定性

## 当前进度（2026-06-04）

### 已完成
- **配置系统**：YAML配置加载、类型安全的dataclass配置、环境变量支持
- **LLM集成**：DeepSeek（chat）+ Qwen text-embedding-v3（embedding，1024维度）
- **向量索引**：基于Redis Stack RediSearch的FLAT索引，支持KNN搜索
- **向量搜索**：相似性搜索、元数据过滤、混合查询（文本+向量）
- **缓存系统**：语义缓存（相似度阈值0.95）+ 嵌入缓存（24小时TTL）
- **对话历史管理**：多轮对话上下文管理，支持会话历史存储和检索
- **意图识别**：基于向量相似度的意图分类和路由
- **Python SDK**：统一客户端接口，支持所有核心功能
- **Web可视化界面**：Vue 3 + FastAPI，支持对话、缓存统计、功能展示
- **测试**：23/23单元测试通过，集成测试全部通过

### 技术要点
- RediSearch KNN查询必须使用`PARAMS 2 BLOB <vector>`语法，DIALECT 2
- LLM和Embedding使用不同provider（DeepSeek vs Qwen），各自独立配置api_key和base_url
- Qwen embedding通过Dashscope OpenAI兼容接口调用
- 语义缓存支持精确匹配和向量相似度匹配两种模式
- 意图识别通过计算用户输入与预定义意图示例的向量相似度实现
